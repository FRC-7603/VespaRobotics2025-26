# VespaRobotics 2025/2026 main repo

Welcome to the **VespaRobotics 2025/26 Season Repository**!  
This repository is dedicated to the VESPA Robotics Team for the **2025–2026 FRC season.**

---

## 📌 Purpose
- MAIN repo of **competition** code for FRC 2025/26 season
- **Only programming team executives inside the Robotics Club would by default have write access to this branch. Generally one should create a pull request to allow executives to review the code and push them for you. This is to prevent untested or bad code to be pushed into this branch, which would be very bad as it would be trusted and used during competition, we don't want our robot to break down in the middle of the competition right?**
